# AI Job Search OS v1.8.1

v1.8.1 makes the move from familiar AI chat to a folder-capable agent easier to understand for people who have never used a coding or agent app.

## What changed

- The landing page now explains AI chat as the consultation space and a folder-capable agent as the AI's work desk.
- The uploaded Migration Coach gives the same explanation before it introduces Codex, Claude Code, Cursor, Antigravity, or another compatible agent.
- Users are told that everyday use remains a normal conversation and does not require coding.
- Users may switch agents by opening the exact same Personal Workspace folder. The instructions recommend one writing agent at a time and explain that copied folders do not synchronize automatically.
- The primary CTA now reads **Mulai Setup — Download 1 File**, with `MULAI_DI_SINI.md` shown as supporting text.

This patch does not change the workspace architecture, tracker modes, dashboard, privacy boundary, or job-search workflow. Automated package and distribution checks pass. Live setup behavior on every named provider remains subject to the platform-specific validation recorded in `VALIDATION.md`.

# v1.6.0 — local workspace release

AI Job Search OS now starts in the AI chat a user already understands and guides them into a folder-capable agent one action at a time. The primary runtime is a Personal Workspace stored locally and opened in Codex, Claude Code, Antigravity IDE, Cursor, or another compatible agent.

The Personal Workspace contains the complete modular workflow, empty JSON tracker state, private profile/application/report folders, and agent-specific entry instructions. It contains no Git metadata, remote, maintainer script, credential, or personal data. The agent must verify a local write/read cycle before onboarding and must never initialize Git, push, publish, or upload workspace data.

Native Skill installation and `PORTABLE_WORKFLOW.md` remain compatibility paths. Local setup, approval-gated fictional onboarding, persistence, and fresh-session recovery passed live acceptance in Codex on Windows. Claude Code, Antigravity IDE, Cursor, the complete nontechnical migration journey, live job discovery, document delivery, and tracker mutation remain unverified.
